# Archive — read-only, never current

The resting place for documents that no longer describe the system: superseded references,
finished workstream files, plans that were overtaken. Move them here whole; don't delete them —
deleted history gets reconstructed from memory, wrong, and then cited.

Two rules, both load-bearing:

1. **Nothing in here is ever current.** An agent may cite an archived file as history ("what did
   we believe in March?"), never as behavior. The constitution's sources-of-truth list names this
   layer last, and never for a live question.
2. **Move, don't edit.** A document enters the archive as it last stood. "Correcting" an archived
   doc forges the historical record — the correction belongs in the live document that superseded
   it, with a link back.

The Librarian's orphan report deliberately ignores this directory: unreachable is the point.
